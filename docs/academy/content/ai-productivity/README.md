## Module 1 — Generative AI Foundations

### Lesson 1.1 — Introduction to Generative AI

**Objectives:** Explain what an LLM does; list three reliable use cases and three failure modes for daily work.

**Teach:** Large language models predict tokens from context. They draft, summarize, and brainstorm well; they invent citations, miss private facts, and can leak sensitive prompts if misused. Productive use means clear goals, short iterations, and human verification.

**Guided demo:** Ask the same question three ways (vague → role+constraints → role+example+checklist). Compare outputs.

**Exercise:** Pick one real work task. Write (a) a bad prompt and (b) an improved prompt with role, audience, format, and constraints.

**Self-check:** Can you name two things the model cannot know without you providing them?

**VIDEO NOT RECORDED — storyboard:** Screen: blank chat → vague prompt → weak answer → improved prompt → checklist output. Shot list: browser chrome, prompt text, scroll of answer, annotation callouts. Transcript stub: “Today we compare vague vs structured prompts…”

### Lesson 1.2 — ChatGPT practical usage

**Objectives:** Configure custom instructions; run a drafting workflow with revision passes.

**Teach:** Separate system/custom guidance from task prompts. Use drafts as scaffolds, not final truth. Keep confidential data out of consumer chats unless your organization approves a tool.

**Exercise:** Create a custom-instruction paragraph for your role (≤120 words). Draft one email with two revision passes (clarity, then tone).

### Lesson 1.3 — Claude and Gemini workflows

**Objectives:** Choose tools by strength (long docs, multimodal, ecosystem) and compare outputs for one task.

**Exercise:** Same research brief in two tools; score accuracy, structure, and actionable next steps (1–5 each).

**Module 1 assignment (checklist):** Workspace setup — accounts, custom instructions, one shared prompt template file. Rubric: completeness 40%, clarity of use-case 40%, privacy note 20%.

## Module 2 — Prompt Engineering & AI Research

### Lesson 2.1 — Prompt engineering

**Objectives:** Apply role, constraints, examples, and iterative refinement.

**Teach:** Structure: Goal → Context → Constraints → Format → Examples → Critique instruction.

**Exercise:** Build 5 prompts for your role using that structure.

### Lesson 2.2 — AI research techniques

**Objectives:** Separate model summary from primary sources; fact-check claims.

**Exercise:** Research a tool you use; produce a one-page brief with sources you opened yourself.

**Graded assignment — Prompt library starter pack:** Deliver 10 reusable prompts with title, use case, prompt body, and verification step. Rubric: coverage 30%, structure 30%, verification habits 25%, clarity 15%.

## Module 3 — Documents & Business Communication

### Lessons 3.1–3.2

**Objectives:** Produce a structured document and professional emails with AI assist without losing your voice.

**Exercise:** One 1–2 page brief + three emails (request, follow-up, decline).

**Assignment — Communication pack:** Same deliverables with before/after prompts attached. Rubric: audience fit 35%, correctness 35%, edit quality 30%.

## Module 4 — Productivity Tools & Workflow Automation

### Lessons 4.1–4.2

**Objectives:** Design a personal AI-assisted workflow; automate only stable, low-risk steps.

**Teach:** Prefer checklists and templates before brittle multi-step bots. Log what stays human (approvals, client facts).

**Capstone — Personal productivity system:** Document and demo one end-to-end workflow (intake → draft → review → send/store). Measurable criteria: time estimate before/after; error/verification checklist; privacy note; 5-minute demo script. Rubric: impact 30%, reliability 30%, verification 20%, presentation 20%.
