### Sample lesson (Module 2)

**Objectives:** Write a clear request email and a polite follow-up.  
**Practice:** Pair or self-record speaking of the same message; peer checklist for clarity and tone.  
**Exercise:** Transform a blunt message into a professional version without losing the ask.

**Formative:** Identify three tone problems in a sample thread.  
**Capstone outline:** Personalized communication pack for the learner’s real workplace context (requires instructor consult).
