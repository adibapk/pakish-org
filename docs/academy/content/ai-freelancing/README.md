## Prerequisites / outcomes

**Prerequisites:** One marketable skill (writing, design, WordPress, data, etc.).
**Outcomes:** Position an offer, write proposals, deliver with AI assist without over-claiming, and handle payment basics safely.

**Important:** Training does not guarantee clients, income, or platform approval.

### Lesson 1.1 — Niche and proof

**Learning objective:** Write a one-sentence offer and list three proof pieces you can actually show.

**Rubric:** Specificity 40%; honest proof 40%; clarity 20%.
